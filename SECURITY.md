# Security policy

## Supported version

Security fixes are made against the latest commit on `main`. This first release does not maintain
older supported branches.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not attach Bluetooth
captures, system logs containing personal data, credentials, or signing material to a public issue.

Include the affected macOS version, SiriRemote version, a minimal reproduction, and the security
impact. Ordinary crashes, compatibility problems, and feature requests belong in the public issue
tracker.
